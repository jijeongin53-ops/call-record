# 📱 갤럭시 통화 녹음 자동 정리 & 옵시디언 동기화 웹앱

갤럭시 스마트폰의 통화 녹음 파일을 구글 드라이브에 자동 백업하고, AI(Google Gemini)를 통해 화자·일시·핵심 키워드·요약·할 일을 추출하여 **구글 드라이브 리포트 및 로컬 옵시디언(Obsidian) 노트**로 자동 저장해주는 통합 관리 웹 애플리케이션입니다.

---

## ✨ 핵심 기능

1. **AI 자동 분석 및 정리 (Gemini 1.5 Flash)**
   - 통화 일시 및 담당자(상대방) 자동 감지
   - 핵심 키워드 3~4개 추출
   - 3~5줄 핵심 요약 및 액션 아이템(Action Items) 체크리스트 생성
   - 화자별 상세 녹취록(Transcript) 변환

2. **옵시디언(Obsidian) 자동 연동**
   - 파일명 규격: `[날짜]_[담당자명]_[주요키워드].md`
   - YAML Frontmatter (태그, 날짜, 담당자, 드라이브 링크 등)
   - 통화 내용 및 구글 드라이브 바로가기 링크 자동 삽입
   - `obsidian://open?file=...` 링크를 통한 원클릭 노트 열기 지원

3. **구글 드라이브 백업 연동**
   - 원본 오디오 파일 및 마크다운 리포트 업로드
   - 전용 공유 뷰어 링크 자동 생성

4. **직관적인 모던 웹 대시보드**
   - 드래그 앤 드롭 파일 업로드
   - 실시간 처리 파이프라인 시각화
   - 원클릭 시뮬레이션 테스트 기능

## 🚀 빠른 시작 가이드

### 1. 의존성 설치 및 서버 실행
```bash
npm install
npm start
```
브라우저에서 `http://localhost:3000` 으로 접속합니다.

### 2. 초기 설정 (웹 대시보드 우측 상단 [연동 설정])
1. **Google Gemini API Key**: [Google AI Studio](https://aistudio.google.com/)에서 무료 발급 후 입력
2. **옵시디언 볼트 경로**: PC의 옵시디언 볼트 폴더 경로 입력 (예: `C:\Users\내계정\Documents\ObsidianVault\Calls`)
3. **구글 드라이브 설정 (선택)**: 특정 구글 드라이브 폴더 ID 지정

### 3. 갤럭시 스마트폰 자동 동기화 3단계
1. **갤럭시 기본 전화 앱**: [설정] → [통화 녹음] → [통화 자동 녹음] 켜기
2. **FolderSync 앱 설치**: 구글 플레이스토어에서 무료 앱 FolderSync 설치 후 구글 드라이브 연결
3. **폴더 페어 생성**: 스마트폰의 `Recordings/Call` 폴더를 구글 드라이브 백업 폴더와 연결
